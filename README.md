# 格ゲー大会マネージャー

格闘ゲームの大会を、スクリーンリーダー（PC-Talker・NVDA）とキーボードだけで運営する Windows 用のツールです。結果を入力すると、次の対戦や順位を読み上げます。観戦する人のために、ブラウザで見られる閲覧ページへ結果を自動で反映することもできます。

現在はテスト版です。

使い方は [Manual (Japanese).txt](<Manual (Japanese).txt>) にあります。

## できること

- シングルエリミネーション、ダブルエリミネーション、総当たりリーグの運営（2〜16 人。ダブルエリミネーションは 3〜16 人）
- 通常戦と、決勝、ルーザーズ決勝、グランドファイナル、3 位決定戦のセット数を別々に設定
- ダブルエリミネーションのリセット戦、シングルエリミネーションの 3 位決定戦
- 試合一覧、選手別の軌跡、次の試合、順位の 4 つの表示の切り替え
- 結果の修正と取り消し。後の試合に影響する修正は、消える試合を確認してから行います
- 保存と読み込み。結果を入れるたびに自動で保存します
- 閲覧ページへの自動反映（任意。自分で用意するサーバーが必要です）

## AI を使って作ったソフトです

ソースコードと文書は、AI（Anthropic の Claude）を使って書きました。何を作るか、読み上げで使いやすいかは作者が決め、スクリーンリーダーで確かめています。あわせて、自動テスト（tests フォルダ）で動作を確かめています。

## 動かす

Windows と Python 3.14 で動作を確かめています。

```
python -m pip install -r requirements.txt
python -X utf8 app/main.py
```

保存したデータは data フォルダに入ります。

## テスト

読み上げとウィンドウの表示を使わずに動きます。公開層のテストの通信は、手元のテスト用のサーバーとの間だけです。

```
python -X utf8 tests/test_domain.py
python -X utf8 tests/test_publish.py
python -X utf8 tests/smoke_app.py
```

結果は tests フォルダに書き出します。終了コード 0 がすべて合格です。

## exe を作る

新しい仮想環境に requirements.txt だけを入れて作ってください。ほかの部品が入った環境で作ると、使っていない部品まで exe に入ります。

```
python -m PyInstaller --noconfirm --clean FGTournament_v1.0.3.spec
```

## オンライン公開のサーバーを用意する

閲覧ページを使うには、PHP が動く自分のサーバーが必要です。このソフトには接続先のサーバーは入っていません。

1. web フォルダの tournament_relay.php を開き、`__ADMIN_KEY__` の行の `__ADMIN_KEY__` を、推測されにくい長い文字列（管理キー）に置き換えます
2. tournament_relay.php と viewer.html を、サーバーの同じフォルダに置きます。HTTPS で開ける場所にしてください
3. 同じフォルダに書き込めるようにします。大会のデータは、その中の t フォルダに保存します
4. t フォルダの一覧が外から見えないように、サーバーのディレクトリ一覧の表示を止めます。閲覧 URL に入っている文字列は、ファイルの名前と同じです
5. アプリの公開メニューの公開設定で、tournament_relay.php の URL と管理キーを入力します

管理キーを書き込んだ tournament_relay.php は、公開の場所に載せないでください。

## フォルダの構成

- `app`: 画面と読み上げ。入り口は `app/main.py`
- `domain`: 大会の進行、組み合わせ、順位、読み上げの文（画面と音声に依存しません）
- `publish`: 閲覧ページへ送る内容の作成と送信
- `web`: 閲覧ページと、サーバーに置く中継の PHP
- `tests`: テスト
