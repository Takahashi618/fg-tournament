格ゲー大会マネージャー v1.0.3 マニュアル
========================================

1. 概要
----------------------------------------
スクリーンリーダー(PC-Talker / NVDA)での操作を前提にした、
格闘ゲーム大会の運営ツールです。
シングルエリミネーション、ダブルエリミネーション、
総当たりリーグの3形式(2〜16人、ダブルエリミは3〜16人)に対応。
結果を入力すると、友人がスマホやPCのブラウザで観戦できる
閲覧ページへ自動反映することもできます(オンライン公開機能、9章)。

2. 動作環境
----------------------------------------
- Windows 10 / 11 (64ビット)
- スクリーンリーダー: PC-Talker または NVDA を推奨
  (無くても操作はできますが、読み上げが出ません)
- インストール不要、管理者権限不要

3. インストールと起動
----------------------------------------
- zipを任意のフォルダに展開します
- fg-tournament-1.0.3-test フォルダの中の
  FGTournament_v1.0.3.exe を実行します
- Program Files の中には置かないでください。保存データを同じフォルダに
  書き込むので、ドキュメントなど書き込めるフォルダに展開します
- 初回起動時にWindowsの保護画面(SmartScreen)が出た場合は
  「詳細情報」からの「実行」で起動できます
- 保存データと設定は同じフォルダ内の data に入ります。
  削除するときはフォルダごと消すだけです
- 旧バージョンから更新するときは、以前のフォルダの data を
  新しいフォルダにコピーすると、保存した大会・公開設定・閲覧URLを
  そのまま引き継げます(コピーしない場合は新規の状態で始まります)

4. 大会を作る
----------------------------------------
Ctrl+N を押すと3つの画面が順に開きます。
 (1) 大会設定 … 大会名、形式、通常戦のセット数、
     決勝(ウィナーズ決勝)・ルーザーズ決勝・グランドファイナル・
     3位決定戦それぞれのセット数(個別に設定可能)、
     リセット戦あり(ダブルエリミ)、3位決定戦あり(シングルエリミ)
 (2) 選手登録 … 1行に1人ずつ名前を入力(2〜16人)。
     Enterで改行するたびに、入力した名前と人数を読み上げます
     (例:「田中、1人目」)。入力欄からTabで「次へ」ボタンに移動
 (3) 並び順 … F8でシャッフル。読み上げで確認して「この順で生成」
生成されるとメイン画面の一覧に全試合が並びます。
シードで埋まらない枠は不戦勝として自動処理されます。

5. メイン画面と4つのビュー(F6で切替)
----------------------------------------
 (1) ラウンド別試合一覧 … 全試合を上下キーで読み上げ
 (2) 選手別の軌跡 … 各選手のこれまでの勝敗と次の試合
 (3) 次の試合 … いま対戦できる試合を消化順に表示
 (4) 順位・状況 … 進行中は勝ち残りと敗退状況、終了後は確定順位
F5でいつでも全体状況(進行数、次の試合、優勝者)を読み上げます。

6. 結果の入力
----------------------------------------
一覧で試合を選んで Enter を押します。
「田中 2対0」「田中 2対1」「鈴木 2対1」…「伊藤の不戦勝」のような
候補一覧が開くので、上下で選んで Enter で確定。
確定すると次のように読み上げます。
「田中の勝ち、2対0。田中はウィナーズ決勝へ。伊藤はルーザーズ準決勝へ。」
ダブルエリミのグランドファイナルで敗者側が勝った場合は
自動でリセット戦が追加されます。

7. 修正と取り消し
----------------------------------------
- Ctrl+Z … 直前の入力を取り消します。
  取り消した試合の対戦カードを読み上げるので、何を戻したか分かります
- 入力済みの試合で Enter … 結果の修正です。
  勝者が変わる修正では、影響を受けてクリアされる下流の試合一覧を
  確認してから実行します。スコアだけの訂正なら他試合に影響しません

8. 保存と読み込み
----------------------------------------
- 結果を入れるたびに data フォルダへ自動保存されます
- Ctrl+S … 上書き保存 / Ctrl+Shift+S … 名前を付けて保存
- Ctrl+O … 保存した大会を開く(途中からの再開もできます)

9. オンライン公開(任意)
----------------------------------------
結果を入力するたびに閲覧ページへ自動反映し、友人が各自の
スマホ・PCで観戦できる機能です。
- 利用には、中継サーバー(relay)のURLと「管理キー」が必要です。
  どちらもzipには含まれていません。サーバーに置くファイルと手順は、
  https://github.com/Takahashi618/fg-tournament の web フォルダと、
  同じページの説明の「オンライン公開のサーバーを用意する」にあります。
  サーバーを運営している人がいれば、その人から受け取っても使えます
- 設定手順: 公開メニュー → 公開設定 → relayのURLと管理キーを入力 →
  「オンライン公開を有効にする」にチェック → 「閲覧URLを発行」 → 保存
  (URLとキーは一度入れれば記憶されます)
- 公開メニュー → 「閲覧URLをコピー」で、友人に送るURLが
  クリップボードに入ります
- 有効中は結果入力のたびに自動アップロードされます。
  成功時は何も読み上げず、失敗したときだけ警告が入ります。
  Ctrl+U でいつでも手動アップロードできます
- 閲覧URLを知っている人だけが見られます。URLを変えたいときは
  公開設定の「閲覧URLを発行(再発行)」で作り直してください
  (古いURLは無効になります)

10. 閲覧ページの使い方(観戦する友人向け)
----------------------------------------
- 届いたURLをブラウザで開くだけです。15秒ごとに自動更新されます
- 「リスト表示」と「ブラケット表示」をボタンで切替できます。
  リスト表示はスクリーンリーダーでもそのまま読めます
- 結果が入ると「更新: ◯◯の勝ち…」という1行の通知が入ります
- 順位表は表(テーブル)で、進行中は勝ち残りと敗退状況が読めます

11. キー操作一覧
----------------------------------------
Enter        選択した試合の結果入力(入力済みなら修正)
F5           全体状況の読み上げ
F6           ビュー切替(ラウンド別 → 選手別 → 次の試合 → 順位)
F1           キー操作一覧
Ctrl+Z       直前の結果入力の取り消し
Ctrl+N       新規大会の作成
Ctrl+O       大会ファイルを開く
Ctrl+S       上書き保存
Ctrl+Shift+S 名前を付けて保存
Ctrl+U       今すぐアップロード(公開が有効なとき)
F8           シャッフル(並び順ダイアログ内)
Esc          ダイアログを閉じる(中止)

12. よくある質問・トラブル
----------------------------------------
Q. 読み上げがない
A. PC-Talker または NVDA が起動しているか確認してください。

Q. 「管理キーが未設定です」「relayのURLが未設定です」と言われる
A. 9章の設定手順を確認してください。

Q. アップロード失敗の警告が出た
A. インターネット接続を確認して Ctrl+U で再送してください。
   閲覧ページには最後に成功した内容が表示され続けます。

Q. BO3の試合で「3対0」が入れられない
A. BO3は2本先取なのでスコアは「2対x」です。候補一覧には
   その試合のセット数に合う組み合わせだけが並びます。

Q. 結果を間違えて入れた
A. 直後なら Ctrl+Z、あとから気づいた場合はその試合で Enter を
   押して修正してください(7章)。

Q. 参加人数のわりに試合数が多い気がする
A. 全体状況(F5)や閲覧ページの試合数は、実際に対戦が行われる
   試合だけを数えています(シードによる不戦は含みません)。
   ダブルエリミのリセット戦は、発生が決まった時点で1試合
   加算されます。
